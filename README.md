The Student Result System is a C++ based application developed to manage student academic records and results efficiently. It allows users to add student details, calculate results, display all student records, search for students using their roll numbers, identify top-performing students, and display failed students.
The main objective of this project is to simplify student result management, reduce manual work, and provide accurate academic information through a simple menu-driven interface.
Key Features:
Add Student Details
Calculate Student Results
Display All Student Results
Search Student by Roll Number
Display Topper(s)
Display Failed Students
Menu-Driven Interface

Technology Used: C++
